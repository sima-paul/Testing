THE SMITA UNIVERSE - VERSION 2

1. Extract this ZIP.
2. Add your music:
   - Open assets/music/
   - Copy your song into this folder.
   - Rename it exactly: smita-song.mp3
   - If your file is M4A/WAV, tell me its extension and I can adjust the code.
3. Open index.html in Chrome.
4. Use the top navigation to visit each page.
5. Tap the Music button once to start/stop music. Browsers require a tap before audio can play.
6. For a published website, add your real photos to assets/photos and I can wire them into the gallery.

Files:
- index.html: Welcome page
- memories.html: Photo gallery
- message.html: Personal note
- surprise.html: Final surprise
- style.css: Shared lavender/pink styling
- script.js: Music and interactions

NOTE:
This basic multi-page version reloads when moving between pages, so the music may restart/stop during navigation. Keeping uninterrupted music across page changes requires a more advanced shared player setup.
